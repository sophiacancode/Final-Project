# Project Retrospective

## Project Name

Break Free: A Wellness App

## What Went Well?

One part of the project that went well was developing the main concept for Break Free. The purpose of the app became clear early in the project: help teenagers and young adults take intentional breaks from their phones through short and engaging activities.

Creating the website structure also went well. The project was divided into a homepage, an About page, and a shared stylesheet. This made it easier to organize the content and maintain a consistent design across both pages.

Another positive part of the project was applying concepts from previous assignments. I was able to use HTML, CSS, project planning, user experience concepts, and documentation together in one project.

## What Went Wrong?

One challenge was organizing all of the project requirements. There were several different files and documents required, including the HTML pages, CSS stylesheet, project scope, project plan, retrospective, and README.

Another challenge was working with GitHub and GitHub Pages. Understanding where files needed to be located and how GitHub Pages uses the repository structure took some trial and error.

The project also required learning how to connect the planning documents with the actual website. It was important to make sure that the project scope described what the website and app concept actually included.

## What Would I Do Differently?

If I completed the project again, I would organize the repository structure at the beginning instead of adding and organizing files later. I would create the required folders and files first and then work through them one at a time.

I would also create a checklist based on the project requirements before beginning development. This would make it easier to keep track of completed tasks and reduce confusion.

Finally, I would test the website earlier in the development process. Testing the links and layout as each page is created would make it easier to find and fix problems before completing the rest of the project.

## Overall Reflection

This project helped me understand how planning, design, development, and documentation work together when creating a digital product. Building Break Free required more than simply writing HTML and CSS. I also had to define the project's purpose, identify the target audience, plan possible risks, organize tasks, and reflect on the development process.
