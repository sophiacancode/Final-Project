# Break Free: A Wellness App

## Project Overview

Break Free is a wellness app concept designed to help teenagers and young adults take intentional breaks from their phones.

Instead of simply telling users to put their phones down, Break Free provides short activities that encourage users to move, think, explore, and interact with their surroundings.

This project demonstrates the Break Free concept through a two-page website prototype.

## Project Goals

* Encourage intentional breaks from phone use.
* Provide short and engaging activities.
* Encourage movement and interaction with the user's surroundings.
* Help users track completed challenges and progress.
* Create a simple and easy-to-use experience.

## Website

The website includes two pages:

* **Home:** Introduces Break Free and explains how the app works.
* **About:** Explains the purpose, activities, target audience, and goals of the app.

## Project Features

The Break Free concept includes:

* Start a Break
* Activity selection
* Math challenges
* Mini games
* Timed breaks
* Photo challenges
* Activity history
* Progress tracking

## Project Scope

This project focuses on creating a two-page website prototype for the Break Free concept.

The project does not include a fully functional mobile application, user accounts, databases, push notifications, payments, or app-store deployment.
